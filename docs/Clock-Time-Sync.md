# 时钟时间同步

在「像素屏 · 时钟」点击「立即同步时间」，将电脑当前的本地日期、时分秒发送到音响。

「启动应用时自动同步时间」默认开启，修改后自动保存。包含托盘启动；启动时未找到设备，会在本次应用中选中设备后尝试。每次进程成功校时一次，页面切换或重复设备选择不会重复触发；手动按钮仍可随时使用。关闭开关后，下次启动不自动校时。

校时不会切换屏幕样式，也不会改变音响的 12/24 小时制。界面显示本次运行最近发送的校时时间；失败不会阻止应用和歌词服务启动，可重新选择设备或点击按钮重试。

## SDK

```csharp
var client = PixelBarSdk.ConnectPrimary();
DateTimeOffset sentAt = client.SyncTime();
```

也可显式传入 `DateTimeOffset`。使用该值的年月日时分秒字段，不转成 UTC；设备保存的是本地墙上时间。

## 协议依据和检查

本机 A160 的 EC/D8 功能响应中，B26 为 `08`，bit 3 声明支持完整日期校准，B20/B21 的其他校时格式未启用。与官方本地程序的 B26 构包格式一致：

- 命令 `EC/77`，载荷 9 字节：年份大端 2 字节、月、日、时、分、秒、制式、上下午。
- 制式写 `00` 保留当前设置；上下午字段在 12 点前为 `00`，12 点起为 `01`。
- HID 报告 64 字节，校验为除 report ID `2E` 外的头部及载荷字节之和的低 8 位。
- 官方将 `EC/77` 响应的首个载荷字节 `01` 解释为校准成功。

回归入口：`scripts/test-lyrics-page.ps1 -PublishDirectory publish/app-clock-sync`。包含固定报文、闰日/跨年/时区、开关持久化、启动并发去重、无设备等待、失败重试和时钟页反复导航。离线回归不向音响发送数据，也不操作鼠标或键盘。

本功能依据 A160 的功能标识和官方构包规则实现；A106 未作此次实机回归。
